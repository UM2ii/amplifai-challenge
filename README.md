## Reporting a problem with the site

Found a broken link, a typo, or an out-of-date date? Please [open an issue](https://github.com/UM-IHC-CA2i/amplifai-challenge/issues). For questions about the challenge itself (e.g. data, rules, submissions, or scoring) - email [amplifai@som.umaryland.edu](mailto:amplifai@som.umaryland.edu) or check the [FAQ](https://um-ihc-ca2i.github.io/amplifai-challenge/faq.html) first.

## Citation

If you use the AMPLIFAI data or refer to the challenge in your work, please see the [papers page](https://um-ihc-ca2i.github.io/amplifai-challenge/papers.html) for the dataset preprint and the preferred citation.
